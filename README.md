# Beecrowd Solutions

A collection of Python solutions for programming problems from [Beecrowd](https://www.beecrowd.com.br/).

This repository contains solutions focused on programming fundamentals, mathematical problem solving, algorithms, control flow, loops, conditionals, and other competitive programming concepts.

## Overview

The solutions are organized by their Beecrowd problem ID.

Each Python file corresponds to a specific problem and contains a standalone solution designed to be submitted to the Beecrowd online judge.

## Running a Solution

Make sure Python 3 is installed.

Run any solution with:

```bash
python 1021.py
```

Replace `1021.py` with the problem file you want to execute.

For problems that require input, provide the required input through the terminal according to the problem statement.
